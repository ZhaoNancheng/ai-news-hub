### 关键学习点

1. **VitePress 配置**
   - `config.mjs` 是核心配置文件
   - 支持 ESM 模块格式（不是 .js）
   - `buildCommand` 和 `outputDirectory` 对 Vercel 部署至关重要

2. **Vercel 部署配置**
   - `vercel.json` 不能同时使用 `routes` 和 `rewrites`
   - 静态网站只需配置 `outputDirectory`
   - Vercel 自动检测并构建

3. **项目结构最佳实践**
   - 文档放在 `docs/` 目录
   - 配置在 `docs/.vitepress/`
   - 构建输出在 `docs/.vitepress/dist/`

### 自动化流程

```
1. Cron 触发（每天 22:00）
   ↓
2. 调用 auto-update-ai-news.sh
   ↓
3. 调用 daily-ai-news-skill 获取新闻
   ↓
4. 生成 Markdown 文件（docs/news/YYYY-MM-DD.md）
   ↓
5. 更新首页索引（docs/latest-news.md）
   ↓
6. Git commit 并 push
   ↓
7. Vercel 自动检测并部署
```

### 新闻文件格式

每个新闻文件包含：
- **元数据**: 更新时间、时间戳、日期
- **学术研究**: arXiv 最新论文（AI Agent、多智能体）
- **重大公告**: 产品发布、模型更新
- **研究论文**: 学术突破
- **产业商业**: 融资、并购、合作
- **工具应用**: 新工具、开源项目
- **政策伦理**: AI 监管、安全讨论
